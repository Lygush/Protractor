# Протрактор — цифровой угломер на MPU6050

Цифровой угломер/уклономер на связке LGT8F328P + MPU6050 (DMP) + OLED 128×64.
Firmware крайне ограничен по флешу (29 696 байт) — каждый байт на счету,
многие решения в коде продиктованы именно этим.

## Железо
- **МК**: LGT8F328P (Arduino-совместимый, framework `arduino`, платформа `lgt8f`)
- **Датчик**: MPU6050 (гироскоп + акселерометр, углы считает встроенный DMP)
- **Дисплей**: OLED 128×64, SSD1306, I²C
- **Питание**: Li-ion 3.7В, заряд оценивается через резистивный делитель на АЦП
- **Управление**: 3 кнопки — zero (D8), mode (D7), menu (D6)
- **Зуммер**: D3, тон генерируется аппаратным таймером Timer2 (ISR), без software bit-bang

## Режимы отображения
- **90°** — угол в диапазоне ±99.9°
- **90° + уставка** — ввод целевого угла по разрядам, звук/светодиод при достижении, стрелка направления к цели
- **360°** — угол 0–359°
- **Радианы** — угол в долях π

Переключение режимов — клик `mode`, назад по кругу — удержание `mode`.
Клик `zero` — заморозить показание (HOLD), удержание `zero` — обнулить угол
(с "умным" ожиданием стабильности показаний перед фиксацией).

## Меню настроек (клик `menu`, удержание — выход)
Калибровка, ось измерения (X/Y), единицы (Deg/%/мм-на-метр — см. известные
ограничения ниже), громкость зуммера, яркость экрана, таймаут ухода в сон.
Настройки сохраняются в EEPROM (эмуляция через flash, специфичная для LGT8F328P).

## Энергосбережение
При бездействии (угол не меняется дольше таймаута) МК уходит в
`SLEEP_MODE_PWR_DOWN`, DMP датчика тоже усыпляется; пробуждение — по
прерыванию на любой из кнопок (PCINT).

## Библиотеки (`lib/`)
- **GyverOLED** — вывод на OLED (без буфера кадра — `OLED_NO_BUFFER`, экономит ~1КБ RAM)
- **GyverButton** — клик/удержание кнопок
- **MPU6050** + **I2Cdev** — работа с датчиком и его DMP (адаптированный порт
  библиотеки InvenSense; `PrintActiveOffsets()` заглушена под флагом
  `MPU6050_PRINT_OFFSETS`, чтобы не тянуть в релиз Serial/Print)

Сборка использует `-ffunction-sections -fdata-sections -Wl,--gc-sections -flto`
(см. `platformio.ini`) — линкер и так выбрасывает неиспользуемый код из
библиотек, поэтому там держать используются только реально нужные функции.

## Известные ограничения
- Единицы **%** и **мм-на-метр** выбираются в меню, но пока не влияют на
  показания — сюда нужна доработка (см. `Задачи.txt` и комментарий в
  `oled.cpp` у `OLED_Degrees_90::update_angle_value`).
- Иконки стрелок влево/вправо и лого лягушки — см. `Задачи.txt` п.3.

## Сборка
PlatformIO, окружение `env:LGT8F328P` (см. `platformio.ini`).
